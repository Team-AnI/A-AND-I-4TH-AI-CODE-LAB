# Lab 02 · Autograd와 미분 이해하기

> **한 줄 요약:** Autograd는 **"네가 한 모든 연산을 기억해 뒀다가, 역순으로 미분해주는 비서"**다.

## 🎯 이 실습에서 얻어야 할 것

- `requires_grad=True`가 **무엇을 켜는 스위치**인지 설명할 수 있다.
- 수동으로 계산한 미분 값과 `.backward()` 결과가 **왜 같아야 하는지** 설명할 수 있다.
- 훈련 루프의 **네 줄** — `forward / loss / backward / step` — 각각이 어떤 일을 하는지 구분한다.

## 🗺️ 전체 지도 (Big Picture)

```
   (Forward 방향)
   A, B  ──→  f(A,B)  ──→  Loss
                               │
   A.grad, B.grad  ←── backward│   (Backward 방향)
```

**핵심 통찰:** 딥러닝의 학습 = "Loss를 줄이는 방향"을 찾는 것. 그런데 그 "방향"이란 곧 **Loss의 기울기(Gradient)**입니다. Autograd는 이 기울기를 자동으로 계산해 주는 엔진입니다.

## 🧠 핵심 개념 요약

| 개념 | 한 줄 정의 | 주의점 |
|------|-----------|--------|
| **`requires_grad=True`** | "이 Tensor를 포함한 연산을 추적하라"는 신호 | leaf tensor에만 직접 설정 가능 |
| **`grad_fn`** | 이 Tensor가 **어떤 연산으로 만들어졌는지** 기록 | 계산 그래프의 노드 |
| **`.backward()`** | 역방향으로 그래프를 타고 내려가며 미분 계산 | 스칼라에만 바로 호출 가능 |
| **`.grad`** | 누적된 기울기가 저장되는 속성 | `zero_grad()` 없이 놔두면 **누적됨** |
| **`torch.no_grad()`** | 추적을 일시 중단 (추론·평가 시 필수) | 메모리·속도 이득 |

### 🤔 자주 헷갈리는 포인트

1. **Gradient는 누적된다** — 매 스텝 `optimizer.zero_grad()` 가 필요한 이유.
2. **`.backward()`는 스칼라에서만** — 벡터 Loss에는 `loss.sum().backward()` 또는 `gradient=` 인자가 필요.
3. **`.detach()` vs `torch.no_grad()`** — 전자는 특정 Tensor만, 후자는 블록 전체.
4. **Leaf tensor** — 사용자가 직접 만든 Tensor. 중간 결과물(`y = w*x`)의 `.grad`는 기본적으로 저장되지 않음.

### 📐 이 실습의 수식 복습

$$L = (A \cdot B^2 + 3A) \cdot B = AB^3 + 3AB$$

$$\frac{\partial L}{\partial A} = B^3 + 3B, \qquad \frac{\partial L}{\partial B} = 3AB^2 + 3A$$

$A=2, B=3$ 대입 → $\partial L/\partial A = 36$, $\partial L/\partial B = 60$.  
**PyTorch 결과와 정확히 일치하는지 직접 확인하세요.**
