# Lab 03 · MLP 모델 구축 및 훈련 파이프라인 완성

> **한 줄 요약:** "모델을 짜는 일"과 "모델을 학습시키는 일"은 **분리**되어 있다. 이 분리를 이해하면 PyTorch의 90%를 이해한 것이다.

## 🎯 이 실습에서 얻어야 할 것

- `nn.Module`을 상속받아 **나만의 모델 클래스**를 정의할 수 있다.
- 훈련 루프의 **4단계** (Forward → Loss → Backward → Step)를 암기하지 않고 **원리로** 작성할 수 있다.
- Loss 곡선·정확도 곡선·결정 경계를 보며 **모델이 실제로 배우고 있는지** 판단할 수 있다.

## 🗺️ 전체 지도 (Big Picture)

```
┌─────────── 재사용되는 뼈대 (훈련 루프) ───────────┐
│                                                  │
│   for epoch in range(E):                         │
│       for x, y in loader:                        │
│           ┌─ forward ──┐                         │
│           │  logits =  │ ← 여기에 들어가는 "모델"만  │
│           │  model(x)  │   바꾸면 MLP/CNN/Transformer │
│           └────────────┘   모두 학습 가능         │
│           loss = criterion(logits, y)            │
│           optimizer.zero_grad()                  │
│           loss.backward()                        │
│           optimizer.step()                       │
│                                                  │
└──────────────────────────────────────────────────┘
```

## 🧠 핵심 개념 요약

| 구성요소 | 역할 | 이번 실습에서 쓴 것 |
|---------|------|---------------------|
| **Model (`nn.Module`)** | 입력을 출력으로 변환하는 함수 | `MLP` 클래스 (Linear + ReLU) |
| **Loss (`nn.*Loss`)** | "얼마나 틀렸나" 를 숫자로 | `CrossEntropyLoss` |
| **Optimizer (`torch.optim.*`)** | grad를 받아 파라미터를 수정 | `Adam` |
| **DataLoader** | 데이터를 미니배치로 공급 | `TensorDataset` + `DataLoader` |

### 🤔 자주 헷갈리는 포인트

1. **`model.train()` / `model.eval()`** — Dropout·BatchNorm의 동작이 달라짐. 추론 시 반드시 `eval()`.
2. **`CrossEntropyLoss` 에는 Softmax가 들어있다** — 모델 마지막에 Softmax를 또 달면 **이중 적용**이 되어 학습이 망가짐.
3. **`optimizer.zero_grad()` 의 위치** — `backward()` 전이기만 하면 어디든 OK. 보통 `forward` 직후/`backward` 직전에 둠.
4. **`.item()` vs Tensor** — Loss 값을 기록할 때 `.item()`으로 꺼내지 않으면 계산 그래프가 계속 붙어서 메모리 누수.

### 📊 학습이 잘 되는지 판단하는 3가지 시선

1. **Loss 곡선** — 꾸준히 감소하는가? 진동/발산하면 `lr`이 너무 큼.
2. **Train vs Test 격차** — 벌어지면 overfitting.
3. **결정 경계(Decision Boundary)** — 2D 문제에서는 눈으로 직접 확인 가능.

## ✍️ 직접 해보기 (변형 과제)

2. 활성화 함수를 `ReLU` → `Sigmoid` 로 바꾸면 학습 속도가 달라질까요? (힌트: vanishing gradient)
3. `optimizer` 를 `SGD(lr=0.01)` 로 바꿔 보세요. Adam과 수렴 속도 차이를 관찰.
4. **일부러 버그 만들기:** `optimizer.zero_grad()` 를 지워 보세요. 어떻게 망가지나요?
