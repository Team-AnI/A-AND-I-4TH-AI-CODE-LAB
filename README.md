# AI-code-lab · 추천시스템 기초부터 프로젝트까지

> 딥러닝의 기본기부터 **추천시스템 실무 파이프라인**까지, 13주에 걸쳐 **직접 코드로 만들어보며** 체득하는 실습 중심 커리큘럼입니다.

## 🎯 이 커리큘럼이 지향하는 것

- **"읽을 수 있는 사람"이 아닌 "구성 원리로 이해하는 사람"** 을 만듭니다.
- 이론 영상 → 실습 → AI 심화 학습의 **3박자 사이클**을 반복하여 지식을 장기 기억화합니다.
- 단순 지식 전달이 아닌, **스스로 질문을 설계하고 답을 구성하는 메타인지 능력**을 기릅니다.

## 🗺️ 전체 학습 흐름

```
[기초 체력]          [추천시스템 이론/실습]      [운영/응용]         [내 것으로]
  2주차               3 ~ 7주차                   8 ~ 9주차            10주차 ~
  PyTorch          데이터·임베딩·CF·SASRec      Airflow·배치        논문·프로젝트
```

한 축은 **모델링 역량**(PyTorch → CF → Transformer 기반 SASRec), 다른 축은 **데이터·운영 역량**(EDA → Airflow → 배치 시스템)으로 진행되며, 후반부에 둘이 프로젝트에서 통합됩니다.

## 🧩 왜 이 순서인가

1. **2주차 (PyTorch)** — 앞으로 모든 모델이 이 위에서 돌아갑니다. Tensor·Autograd·훈련 루프는 이후 주차의 공용 언어입니다.
2. **3주차 (MNIST)** — "모델"보다 먼저 **데이터를 다루는 감각**을 기릅니다. 좋은 데이터 없이 좋은 모델은 없습니다.
3. **4~5주차 (임베딩 → CF)** — 추천시스템의 가장 전통적인 뿌리. "유사도"라는 단 하나의 직관으로 얼마나 많은 문제가 풀리는지 체감합니다.
4. **6~7주차 (Transformer → SASRec)** — 최신 추천 모델의 뼈대. "순서"라는 새로운 차원을 다룹니다.
5. **8~9주차 (Airflow → 배치)** — 모델은 **운영될 때** 비로소 가치를 만듭니다. 실무 관점으로 사고의 축을 확장합니다.
6. **10주차~ (논문·프로젝트)** — 지금까지 배운 블록을 **본인의 질문**에 맞게 조립합니다.

## 📚 주차별 학습 방식

모든 실습 주차는 같은 리듬으로 진행됩니다:

```
(1) 코드 실행     20%   →  노트북을 위에서 아래로 따라 실행
(2) 변형 실습     50%   →  "직접 해보기" 문제 + 일부러 버그 만들기
(3) AI 심화 학습  30%   →  5단계 프롬프트로 스스로 이해 검증
```

### 🤖 AI를 "답안지"가 아닌 "튜터"로

각 실습 문서에는 **5단계 AI 학습 프롬프트**가 포함되어 있습니다.

| 단계 | 하는 일 |
|------|---------|
| 구조화 | 주제의 큰 지도를 먼저 그리게 함 |
| 개념 회상 | 내 요약의 빈틈을 AI가 질문으로 지적 |
| 비교/검증 | 경계 조건·예외·대안 탐구 |
| 연결/종합 | 이전/다음 주차 개념과 잇기 |
| 파인만 기법 | 내가 만든 비유를 AI가 평가 |

**핵심:** AI에게 정답을 요구하지 않고, **내 생각의 빈틈을 지적**하게 합니다.
